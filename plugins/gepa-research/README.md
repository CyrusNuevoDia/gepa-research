# gepa-research

The GEPAResearch plugin for Claude Code, Codex, and other Agent Skills hosts.
Ships the canonical `discover` and `optimize` skills plus bundled
`bin/gepa-research` wrappers. The repo root also contains a Pi package manifest
and Pi-specific wrapper skills that delegate back to these canonical skills.

For installation, usage, and documentation, see the main repo README:
https://github.com/CyrusNuevoDia/geparesearch
